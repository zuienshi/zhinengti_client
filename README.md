# 智能体应用启动指南

## 问题说明
我们发现批处理文件(.bat)可能因为编码问题导致无法正常运行。为了确保您能够成功启动应用，请按照以下方法操作。

## 方法一：直接在命令提示符中运行

1. 按下 `Win + R` 键打开运行对话框
2. 输入 `cmd` 并按回车，打开命令提示符
3. 复制并粘贴以下命令，然后按回车：
   ```
   D:\智能体\node_modules\electron\dist\electron.exe D:\智能体
   ```

## 方法二：使用PowerShell

1. 按下 `Win + R` 键打开运行对话框
2. 输入 `powershell` 并按回车，打开PowerShell
3. 复制并粘贴以下命令，然后按回车：
   ```
   & 'D:\智能体\node_modules\electron\dist\electron.exe' 'D:\智能体'
   ```

## 方法三：创建Windows快捷方式

1. 在桌面或任意位置右键点击，选择「新建」→「快捷方式」
2. 在「请键入对象的位置」中输入：
   ```
   D:\智能体\node_modules\electron\dist\electron.exe D:\智能体
   ```
3. 点击「下一步」，然后给快捷方式命名（例如：智能体应用）
4. 点击「完成」
5. 双击创建的快捷方式即可启动应用

## 重要说明

- 应用启动后会显示登录窗口
- 您可以使用任意用户名和密码进行登录（当前为模拟环境）
- 登录成功后将跳转到主界面

## 故障排除

如果应用无法启动，请检查：
1. 确保Node.js和npm已正确安装
2. 确保已运行 `npm install` 安装了所有依赖
3. 确保已运行 `npm run build` 构建了应用

如有其他问题，请联系技术支持。
